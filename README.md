# Divina Terra · Estratégia avançada de trade marketing

Apresentação da 75 LAB, no ar em https://projetos.75lab.com.br/divina-terra-estrategia-avancada/

- Editar `src/` e rodar `python3 fonte/build.py`. `index.html` e `assets/deck.*` são gerados.
- `fonte/ajustar.mjs` recalcula o tamanho de cada tela; `fonte/revisar.mjs` procura texto cortado; `fonte/gerar-pdf.mjs` gera o PDF.
- Bases do cliente, análise e kit em planilha ficam fora do Git.
- Tecla N mostra o roteiro de fala; tecla M abre o sumário.
